# Python Data Processing Project

## Project Overview

This project focuses on exploring, processing, and analyzing the Iris flower dataset using Python in Google Colab.

It is a beginner-level project developed to gain practical experience in Python programming and working with datasets.

## Objectives

- Explore and understand the dataset.
- Perform basic data processing.
- Analyze dataset features.
- Develop practical Python programming skills.

## Dataset

**Iris Dataset**

The Iris dataset contains measurements of iris flowers, including sepal length, sepal width, petal length, and petal width, along with their species.

## Technologies Used

- Python
- Google Colab
- Jupyter Notebook
