# Python Data Processing Project

## Project Overview

This project focuses on using Python for data processing, basic statistical analysis, and data visualisation. The Iris flower dataset is used to explore flower measurements and understand the differences between three Iris species.

The project was developed using Google Colab and Python libraries.

## Dataset

The project uses the Iris flower dataset, which contains measurements of three flower species:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

The dataset includes the following measurements:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Technologies Used

- Python – Programming language
- Pandas – Reading and processing the dataset
- NumPy – Numerical calculations
- Matplotlib – Creating graphs and visualisations
- Google Colab – Writing and running the code

## Project Workflow

1. Selected and loaded the Iris dataset in CSV format.
2. Explored the dataset to understand its structure and contents.
3. Cleaned the data by removing unnecessary columns and duplicate records.
4. Checked for missing values.
5. Calculated five statistical measures: mean, median, minimum, maximum, and standard deviation.
6. Organised the code into reusable functions.
7. Created a scatter plot to compare sepal length and petal length across the three species.
8. Added trend lines to make the relationship between the measurements easier to understand.

## Visualisation

A scatter plot was created to show the relationship between sepal length and petal length for the three Iris species.

The visualisation helps compare their measurement patterns and understand how the species differ from one another.

## How to Run the Project

1. Download the Python notebook (`.ipynb`) from this repository.
2. Open Google Colab.
3. Upload the downloaded notebook.
4. Upload the Iris dataset when prompted.
5. Run the cells in order from beginning to end.
